# Dicionário de Dados — Recruitment Analytics

## Objetivo

Este documento descreve os campos utilizados na base pública anonimizada do projeto Recruitment Analytics.

## Campos

| Campo | Descrição |
|---|---|
| Empresa | Identificação anonimizada da organização |
| Cargo | Categoria generalizada da posição |
| Mês da candidatura | Mês em que ocorreu a candidatura |
| Onde encontrou | Canal de origem da oportunidade |
| Área | Área principal da posição |
| Salário | Faixa salarial informada ou "Em definição" |
| Modelo | Modelo de trabalho da oportunidade |
| Entrevista RH | Indica se houve entrevista com RH |
| Entrevista gestor | Indica se houve entrevista com gestor |
| Nº de entrevistas | Quantidade de entrevistas realizadas |
| Etapa máxima | Etapa mais avançada alcançada no processo |
| Resultado | Situação registrada para o processo |
| Categoria do motivo | Categoria utilizada para análise dos resultados |
| Feedback recebido | Indica se houve retorno da empresa |

## Tratamento de privacidade

A base disponibilizada neste repositório foi anonimizada e adaptada para fins de demonstração e portfólio.

Foram removidos ou generalizados dados que poderiam identificar diretamente processos seletivos específicos, incluindo nomes de empresas, datas exatas, valores salariais exatos e observações pessoais.

## Observação metodológica

As etapas apresentadas no dashboard representam ocorrências registradas nos processos analisados. Elas não devem ser interpretadas necessariamente como um funil sequencial obrigatório, pois diferentes processos podem seguir etapas diferentes.
