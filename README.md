# Recruitment Analytics — Análise de Processos Seletivos

Dashboard interativo desenvolvido em HTML/CSS/JavaScript a partir de uma base pública anonimizada e de um projeto de análise no Power BI.

## Objetivo
Transformar dados de processos seletivos em indicadores para analisar:
- volume de processos;
- evolução das candidaturas;
- etapas alcançadas;
- resultados;
- principais gargalos;
- canais de candidatura;
- faixa salarial;
- modelo de trabalho.

## Tecnologias
Power BI · Excel · DAX · Power Query · Modelagem de dados · HTML · CSS · JavaScript

## Estrutura
- `index.html` — página interativa publicada pelo GitHub Pages.
- `assets/` — estilos e dados utilizados pela página.
- `dados/base_publica_anonima.xlsx` — base anonimizada.
- `documentacao/` — documentação complementar.

## Observação metodológica
A base pública foi anonimizada/adaptada para fins de demonstração e portfólio. Nomes de empresas, datas exatas, valores salariais exatos e observações pessoais não são expostos.

O bloco de etapas é apresentado como **etapas alcançadas nos processos**, e não como um funil sequencial obrigatório, porque os processos não seguem todos a mesma ordem.

## Publicação no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta mantendo a estrutura.
3. Em Settings → Pages, selecione a branch principal e a pasta raiz (`/root`).
4. Salve e aguarde a publicação.
